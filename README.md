# 🦠 COVID-19 Data Analysis Project

This project is a **beginner-friendly Python data analysis project** based on COVID-19 data.

It focuses on analyzing **confirmed, recovered, and death cases**, calculating important metrics, and visualizing trends using charts and graphs.

## 🚀 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## 📝 Notes
I worked on **data cleaning, analysis, calculations, and visualizations** manually.

I used **AI only for limited Python code assistance**, while the overall **logic, workflow, analysis, charts, project handling, and GitHub upload** were done by me.

## ✨ Features
- Analyze confirmed, recovered, and death cases
- Calculate recovery rate and death rate
- Clean and process raw CSV data
- Create charts and graphs for trend visualization
- Understand real-world dataset structure through practical analysis

**Beginner Python Project (Data Analysis & Visualization)**
